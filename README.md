# Datheon Task 1 – Exploratory Data Analysis (EDA)

# Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a Superstore Retail Sales dataset using Python.

The objective is to identify sales trends, profitability patterns, customer behaviour, regional performance, shipping insights, and product returns.

# Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

# Key Analysis Performed
- Data understanding and cleaning
- Sales and profit analysis
- Customer and product analysis
- Regional performance analysis
- Shipping analysis
- Returns analysis
- Outlier detection
- Correlation analysis
- Data visualisation

# Key Business Metrics

| Metric                 | Result |
| Total Sales            | 2,297,200.86 |
| Total Profit           | 286,397.02 |
| Total Orders           | 5,009 |
| Total Customers        | 793 |
| Profit Margin          | 12.47% |

# Key Findings
- Technology generated the highest category sales.
- Furniture had comparatively low profitability.
- November recorded the highest monthly sales.
- December recorded the highest monthly profit.
- Higher discounts were often associated with lower profits.
